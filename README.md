# Lotus-Yunzai

基于 Bun 和 TypeScript 的云崽机器人宿主，支持终端、OneBot 11 和 Milky。

## 快速开始

安装 Git 和 Bun 1.4.4，克隆仓库后在仓库根目录执行：

```sh
bun run bootstrap
bun run start
```

`bootstrap` 一次完成子模块补拉与固定版本核对、依赖安装、管理面板构建、图鉴与固定模板素材、验证码模型、三游面板图库、攻略及配队资源、FFmpeg 与 TuneWeave 准备。交互终端会询问尚未设置的选项；非交互首次安装默认选择最新版图鉴，也可在同一条命令指定 `bun run bootstrap live` 或 `bun run bootstrap latest`。已有设置和有效缓存会复用。初始化成功后直接启动，不需要另跑 `init`。

耗时的初始化与资源维护会显示当前阶段和耗时；可取得总量时显示真实百分比、文件数或下载字节。交互终端实时刷新，重定向到日志时按阶段和间隔输出，长时间处理也会持续报告状态。中断后重新运行同一条初始化命令即可复用有效缓存。

完整日程见[默认定时任务](docs/default-schedule.md)。默认定时按北京时间运行：程序更新 00:30/12:30，三游面板图库 01:00/13:00，初始化后的图鉴 01:30/13:30，配队攻略 02:00/14:00，其余攻略与表格 05:00/17:00。签到默认提前生成次日随机计划；固定模式需手动选择。网易云登录账号存在后，合伙人任务默认于 01:30 执行。显式配置优先。自动群名片只预置后缀，默认关闭，昵称读取当前 QQ 账号；迁移保留原有启用设置。

前台按 Ctrl+C 停止。Linux 或 macOS 安装 PM2 后，使用 `bun run start:bg` 后台启动，`bun run stop` 停止，`bun run logs` 查看日志，`bun run status` 查看后台状态。后台宿主就绪后异常退出会自动恢复。

默认监听 `0.0.0.0:2536`，HTTP 与 OneBot 11 共用端口。协议端反向 WebSocket 地址为 `ws://机器人内网IP:2536/OneBotv11`，内网直连无需令牌；公网接入须配置 `onebot_token`。HTTPS 可由反向代理提供，程序默认不开启 TLS 端口。隔离测试请覆盖端口，避免与生产冲突。

日志沿用 TRSS 的 `[时间][级别]` 格式；前台、后台及 `bun run logs` 共用日志格式，TTY 按级别着色。默认终端具有主人权限；显式设置的主人列表保持不变。普通启动只检查已有资源，补齐安装请重新运行 `bun run bootstrap`。

输入 `#帮助` 获取使用手册链接，输入 `#状态` 查看运行状态。
