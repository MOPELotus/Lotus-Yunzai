# 默认定时任务

以下均为北京时间（Asia/Shanghai）。表中是新安装的默认值；已有显式配置优先。需要账号、订阅或预约的任务，只处理已经登记的对象，不会自动替用户登记。生产迁移另按新的日程执行，保留账号、数据及执行记录。

| 任务 | 默认时间 | 启用条件 |
| --- | --- | --- |
| 程序及已纳管插件更新 | 00:30、12:30 | 通过 `bun run start` 或 `bun run start:bg` 启动；保留子模块固定提交及外部插件更新流程 |
| 三游面板角色图库同步 | 01:00、13:00 | 默认开启，显式关闭图库同步除外 |
| 图鉴版本检查、挑战轮换 | 01:30、13:30 | 完成图鉴初始化；两项串行执行 |
| 配队攻略资源更新 | 02:00、14:00 | 默认开启自动更新；外部指定配队目录不自动覆盖 |
| 角色与进阶攻略、复刻表、深渊参考表 | 05:00、17:00 | 默认开启攻略自动更新 |
| 网易云音乐合伙人 | 01:30 | 已登录网易云账号，且未显式关闭 |
| 次日签到计划生成 | 每日 00:00 | 默认开启签到调度；为已登记档案生成明天的计划 |
| 实际自动签到 | 计划内随机时间，默认范围 00:00—23:30 | 默认随机模式，每分钟扫描到期计划；固定时间需手动切换 |
| 签到计划补登记、补偿检查 | 启动恢复、档案登记或变更时，以及每 10 分钟 | 补齐今天和明天的有效计划；迟到登记默认安排在 23:30—23:59 |
| 游戏、社区签到失败补跑 | 到期扫描处理；按失败记录延迟安排 | 游戏按角色、社区按版块分别处理；通常依次延迟 10、60、180 分钟，后续 360 分钟，结合 23:50/23:59 收尾边界；仅补跑可确认未成功的项目 |
| 前瞻兑换码扫描及自动兑换 | 每 5 分钟 | 自动扫描；仅对已开启自动兑换的档案提交，按兑换记录去重并检查有效期 |
| 体力提醒 | 每 30 分钟检查 | 仅处理已订阅角色，默认提醒冷却 12 小时 |
| 绝区零挑战战绩提醒 | 启动恢复、每分钟检查 | 仅处理已开启提醒的档案 |

游戏、社区签到结果仍优先私聊，私聊不可用再尝试已绑定的通知群。投递或签到结果不确定时保留记录，不当作确定失败重复提交。

自动群名片新安装默认关闭，只预置后缀模板，昵称读取当前 QQ 昵称。群定时禁言、定时日历推送、内容订阅、公告推送、米游币商城预约等按各自登记内容与配置运行，不属于无条件执行的每日任务。定时重启、定时开关机、更新检查通知也不会因本表自动启用。

`bun run bootstrap` 负责首次资源和工具安装；普通启动不补下载图库、攻略、验证码模型或媒体工具。后续资源更新按上表运行，手动更新指令仍可使用。
