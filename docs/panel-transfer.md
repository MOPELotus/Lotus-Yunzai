# 跨机器人交换角色面板

同一个 QQ 账号可以在两台 Lotus-Yunzai 之间交换本人原神、星铁的面板档案。两边应绑定同一个游戏 UID。导入只补当前档案里缺少的角色，已有角色按接收端保留。

## 聊天指令

- 在来源机器人的好友私聊发送 `#导出面板数据 档案1`。星铁使用 `*导出面板数据 档案1`。
- 在接收机器人的好友私聊发送 `#导入面板数据 交接码 档案1`。星铁使用 `*导入面板数据 交接码 档案1`。
- 交接码十分钟有效，确认导入后即停止领取。若接收端提示网络或确认失败，可用同一个码再试。码失效后回来源机器人重新申请。

本机导出 JSON 的命令仍为 `#原神导出面板` 和 `#星铁导出面板`。

## 两端配置

默认关闭。通过各自安装目录的 `config/bot.yaml` 配置，保存后重启。

来源端示例

```yaml
panelTransfer:
  export: 1
  publicOrigin: https://source-bot.example.org
```

接收端示例

```yaml
panelTransfer:
  import: 1
  peers:
    - https://source-bot.example.org
```

权限值 `1` 对已绑定的角色本人开放，`2` 只允许当前机器人主人交换本人角色，`3` 关闭。已有配置使用 `0` 时也要求本人绑定。来源地址填写接收机器人可到达的 HTTPS 协议、域名和可选端口。反向代理应将 `POST /lotus/panel-transfer` 转发给宿主公共 HTTP，并转发请求认证字段。接收端只连接明确列出的来源，遇到跳转即停止。

交接码请只发给接收机器人的好友私聊。来源服务器暂存加密的面板文件，接收机器人核对发令者 QQ、游戏和档案 UID 后领取并解密。
