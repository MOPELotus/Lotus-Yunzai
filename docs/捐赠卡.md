# 捐赠卡

`#捐赠` 默认发出项目的公开捐赠链接。如需同时发图，在部署环境中把 `LOTUS_DONATION_RESOURCES` 指向自己的海报目录，放入 `wechat-lotus.png` 和 `alipay-lotus.jpg`。设置目录只提供给当前宿主，海报会通过指令发给用户。请使用你有权公开、已经核对收款账户的海报。

安装了旧荷花的原字体时，可用现有 `LOTUS_PASSPORT_QR_RESOURCES` 指向其素材目录。海报不可读、图片超出网关限制或发送失败时，仍会发出捐赠链接。卡片底图沿用 Lotus-ReFactor `6e374cd` 中的 Miao 帮助页资源。
