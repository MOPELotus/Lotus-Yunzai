# 独立部署依赖核查

本次按“克隆后只初始化一次即可运行”检查，旧插件目录只允许提供迁移兼容，不能成为默认功能的唯一依赖。

| 核查范围 | 发现与处理 |
| --- | --- |
| 三游公共素材和基础数据 | 原先多个默认路径指向旧 Miao、genshin、ZZZ、flower；现内置背景、图标、立绘、字体以及卡池历史、别名、角色、装备、材料数据，并接入默认入口。 |
| 登录、资料、签到、体力推送 | 原先依赖旧 Lotus / bujidao；固定资源现由仓库提供。 |
| 状态、版本、监控 | 原先默认素材目录被忽略而没有准备入口；现使用内置 Yenai / Miao 公共资源。控制台状态保持文本。 |
| 群设置、点赞、公告、日历、订阅 | 补齐默认背景、字体、头图和帮助图标；虚空深渊固定帮助不再首次调用联网。 |
| 原字体实际使用 | 修复部分绕过原字体直接请求系统字体的绘制路径。按模板使用 HYWH、NZBZ、tttgbnumber、FZB、鸿蒙、yuan、OPPO Sans；原排行字库 Noto Sans CJK SC 也内置。中文及 emoji 的缺字后备不依赖系统安装。 |
| 内存数据库 | 未配置存储的新安装原本跳过连接。现优先验证显式配置；否则初始化检测系统 Valkey，缺失时项目内安装固定官方版本。使用独立认证 Unix Socket，TCP 端口关闭；RDB/AOF 位于 data/valkey。 |
| 游戏注册时间 | 原先只读小飞旧缓存。现有原生私有存储、按角色校验迁移及三游原在线链。活动接口沿用原插件固定版本，测试使用合成响应，未用真实账号确认活动当前开放状态。 |
| 媒体工具 | FFmpeg / TuneWeave 已前置初始化；解包时核验实际归档所需 tar、unzip 或 PowerShell。可选 curl 回退缺失会给出准确诊断。 |
| 公共代码与规则 | 检查了静态相对导入、验证码 JSON、词表、设备 APK、三游计算规则及基础数据，未发现另有缺失或仅存在工作区而未入对应仓库的必要文件。 |

`resources/builtin/manifest.json` 覆盖内置包及各插件原有的公共 resources。完整初始化逐件校验大小和 SHA256，固定资源缺失或损坏即失败；普通不完整的本地主题可以从内置资源补齐，已有有效自定义文件与显式覆盖保留。

无需提交的内容包括账号、Cookie、设备凭据、订阅、用户配置、抽卡与游戏记录、榜单、预约和数据库。这些应由注册流程生成，或在迁移时完整保留，不能作为公共默认内容复制进仓库。

未自动安装的可选依赖包括网易云乐评 `codex` 模式所需的已登录 Codex CLI。默认模式不依赖它。某些玩法使用原有远程试算接口，不冒称已有本地引擎。远程业务接口、账号授权与网络可用性不等于仓库静态依赖完整性。

验证包含原文件摘要、缺失/篡改失败、存储隔离与重启持久化、活动查询合成响应以及离线物理 GPU 出图。图形验收使用 NVIDIA RTX A4000 / Vulkan，并查看输出图片；字体另记录 FontLibrary 注册文件及 Skia 整形实际选中的字体 family，没有以“文件存在”代替实际使用验证。
