# 原版面板渲染

原神、星铁角色面板可以使用本机 Chrome 或 Chromium 渲染原静态模板。主题、立绘、字体和档案继续按各游戏原资源路径读取。启用后，同一宿主的旧 V3 模板仍使用原兼容入口。

在启动 Lotus-Yunzai 的环境中将 `LOTUS_CHROMIUM_EXECUTABLE` 设为已安装的 Chrome 或 Chromium 可执行文件。有物理显卡的无头 Linux 主机可为该进程设置实际使用物理驱动的 Xorg `DISPLAY`。

```sh
LOTUS_CHROMIUM_EXECUTABLE=/usr/bin/chromium DISPLAY=:97 bun run start
```

发送角色面板命令后，运行日志会记录 Chromium 的渲染器名称。只有硬件栅格化正常才出图。渲染进程使用私有调试管道，关闭页面脚本和网络请求。未设置该可执行文件时，使用当前的 Shotium 兼容配置。业务图片完整生成后仍走当前协议的正常发送链路。
