# 图片文字识别

OneBot 11 和 Milky 都可使用 `#ocr`、`#取文字` 或 `#提取文字`。命令优先取当前会话引用消息中的第一张图，否则取当前消息的第一张图。没有图片时可补发一张，或回复「取消」。群开关、私聊权限和账号绑定规则沿用现有设置。

识别由运行 Lotus-Yunzai 的本机执行。Ubuntu 和 Debian 安装 Tesseract 5 与简体中文、英语模型后即可使用：

```sh
sudo apt install tesseract-ocr tesseract-ocr-chi-sim tesseract-ocr-eng
tesseract --version
tesseract --list-langs
```

`--list-langs` 应包含 `chi_sim` 和 `eng`。其他平台可按 [Tesseract 安装文档](https://tesseract-ocr.github.io/tessdoc/Installation.html) 安装。使用自定义模型目录时，在启动环境中将 `TESSDATA_PREFIX` 指向包含这两个 `.traineddata` 文件的目录。PM2 或容器部署应在 Lotus-Yunzai 实际运行的主机或容器内检查命令与模型。

主机从 QQ 媒体地址读取原图。图片数据只送给本机 OCR 进程，文字结果返回原会话。每次处理一张图，图片上限 8 MiB，最长边 4096 像素，总面积上限 1200 万像素。缺引擎、缺模型、识别忙或超时会分别提示，其他功能仍可照常使用。
