# 图片文字识别

OneBot 11 和 Milky 都可使用 `#ocr`、`#取文字` 或 `#提取文字`。命令优先取当前会话引用消息中的第一张图，否则取当前消息的第一张图。没有图片时可补发一张，或回复「取消」。群开关、私聊权限和账号绑定规则沿用现有设置。

识别由 Lotus-Yunzai 用 Bun 执行，图片通过本机 Tesseract 5 原生库识别。在 Ubuntu 或 Debian 可安装原生库和两个语言模型。

```sh
sudo apt install libtesseract5 tesseract-ocr-chi-sim tesseract-ocr-eng
```

默认使用发行版的模型目录。已有 Tesseract 5 安装可继续复用原库和模型。自定义目录仍通过启动环境中的 `TESSDATA_PREFIX` 指向包含 `chi_sim.traineddata` 与 `eng.traineddata` 的目录。PM2 或容器部署应在 Lotus-Yunzai 实际运行的环境中安装库和模型。

主机从 QQ 媒体地址读取原图。图片数据只送给同一 Bun 启动的本机识别进程，文字结果返回原会话。每次处理一张图，图片上限 8 MiB，最长边 4096 像素，总面积上限 1200 万像素。缺引擎、缺模型、识别忙或超时会分别提示，其他功能仍可照常使用。
