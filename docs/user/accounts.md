# 账号绑定与管理

Lotus-Yunzai 将本地米游社凭据、设备信息、三游角色、国际服 Cookie 与云游戏 Token 按**档案编号（1–255）**独立存储。默认档案为 **1**，绝大多数指令省略编号时即操作档案 1（例如 `#扫码登录` 等同于 `#扫码登录1`）。

> **安全与会话提示**
> - 扫码登录、设备绑定、国际服 Cookie 与云游戏 Token 绑定、以及完整本人角色目录查询，均须在**当前连接机器人的好友私聊**中进行，切勿在群聊发送 Cookie、Token 或设备资料。
> - 档案中的“已登录（`loggedIn`）”仅表示本地同时存有 Cookie 与 SToken 字段，不代表凭据此刻一定通过米游社实时认证；遇到接口失效时请使用 `#刷新cookie` 或重新 `#扫码登录`。

## 三种绑定方式的区别

Lotus-Yunzai 提供三种不同层级的账号/UID 接入方式，按需选用即可：

| 方式 | 典型指令 | 是否需要登录 | 可用功能与边界 |
| :--- | :--- | :--- | :--- |
| **米游社扫码登录** | `#扫码登录` | 是（好友私聊） | 本地保存 Cookie、SToken、设备与三游角色；支持签到、兑换码、战绩、抽卡、本人面板等 |
| **公开 UID 登记** | `#登记公开UID <UID>` | 否 | 仅保存公开 UID 列表（每游戏最多 99 个），用于查询 Enka / Mihomo 公开展板，无账号授权 |
| **UID 签名验证** | `#绑定原神UID <UID>` | 否（好友私聊） | 通过游戏内临时签名核验本人身份（口令 24 小时有效），验证后 30 分钟内可在私聊执行 `#原神导出面板 <UID>` 等操作，不保存登录凭据 |

若需通过 UID 签名验证临时导出角色面板，具体步骤与指令参见[角色面板查询](panels.md)。

## 米游社扫码登录与多档案

系统已停用账号密码登录，所有米游社账号须通过**当前连接机器人的好友私聊**扫码绑定。

### 扫码登录步骤

1. 在好友私聊发送 `#扫码登录`（默认档案 1）或 `#扫码登录2`（指定档案 2，支持 `1`–`255`；也支持 `#二维码登录`、`#米游社登录`）。
2. 收到登录二维码后，使用米游社 App 扫码并在手机端确认登录。
3. 登录信息保存后，系统会自动同步该账号下的原神、崩坏：星穹铁道、绝区零角色。若提示角色暂未同步，可发送 `#同步角色`（或 `#同步角色2`）手动重试。

### 取消登录等待

- 二维码生成后等待确认期间，若需放弃当前会话的登录，发送 `#取消扫码登录`（或 `#取消扫码登录2`）即可中止。
- 若手机端已点击确认且后台正在写入档案，则无法中途取消，需等待保存完成。

## 档案查看、刷新与清除

| 功能 | 常用指令 | 说明与范围差异 |
| :--- | :--- | :--- |
| **查看档案列表** | `#登录列表`（别名 `#账号列表`） | 列出当前 QQ 已创建的档案及状态；建议在私聊查看，避免在群内暴露资料 |
| **查看档案详情** | `#配置` / `#配置2` | 展示通行证、Cookie/SToken 保存状态（敏感字段已脱敏）、设备状态、三游角色、签到与国际服/云游戏配置 |
| **同步三游角色** | `#同步角色` / `#同步角色2` | 重新拉取该档案下的原神、星铁、绝区零角色目录 |
| **刷新登录凭据** | `#刷新cookie` / `#刷新cookie2` | **不带档号刷新当前 QQ 名下全部档案**；带档号仅刷新指定档案。受 `checkin.refresh` 策略控制（默认 `inherit`，未设置 `deny` 等限制策略时普通用户可用） |
| **清除登录凭据** | `#清除登录` / `#清除登录2` | **不带档号仅清除档案 1**。仅清空 Cookie/SToken 等登录凭据，保留设备、角色与签到设置 |

> **刷新与清除的范围差异**
> - `#刷新cookie` 省略档号时会遍历你名下所有档案；`#清除登录` 省略档号时**只清除档案 1**，不会误清档案 2 及后续档案。
> - `#清除登录` 不会删除整份档案：已绑定的设备信息、角色列表和签到开关都会保留，方便之后重新扫码恢复。
> - 旧版 `#删除ck`（及 `#星铁删除ck`、`#绝区零删除ck`）会按游戏查找已登录且有选定角色的档案；若多个档案同时符合，系统会拒绝猜测并提示改用 `#清除登录<档号>` 指定。

## 本人角色目录与默认档案切换

登录多个档案或单个账号拥有多个区服角色时，可通过本人角色目录查看与切换当前角色。**完整本人角色目录与选槽操作仅在好友私聊可用**，群聊不会展示个人角色资料。

### 查看与按序号切换本人角色

前缀 `#` 对应原神、`*` 对应星铁、`%` 对应绝区零（也可写为 `#原神UID`、`#星铁UID`、`#绝区零UID`）：

| 指令示例 | 作用 | 是否改变游戏默认档案 |
| :--- | :--- | :--- |
| `#UID` / `*UID` / `%UID` | 在好友私聊列出全部已登录档案的三游角色目录与序号（1–99），并附带公开 UID 引用 | 否 |
| `#UID 档案2` | 仅列出档案 2 的三游角色目录 | 否 |
| `#UID2` / `*UID2` / `%UID2` | 选中对应游戏目录中的第 2 个角色，设为所在档案当前角色 | **是**（将该角色所在档案记为该游戏的默认档案） |
| `#UID2 档案2` | 在**档案 2** 中选中对应游戏的第 2 个角色 | **否**（显式指定档案不改变该游戏默认档案） |
| `#切换原神UID <UID>` / `#设置星铁UID2 <UID>` | 在指定档案（省略档号为档案 1）内按实际游戏 UID 选中角色（须为 8–10 位数字，且已同步至目标档案本人角色目录，不用于登记新角色） | **否**（显式或单档操作不改全局默认路由） |

> **默认档案路由规则**
> 当你通过不带 `档案N` 的序号指令（如 `#UID2`、`*UID3`、`%UID2`）切换角色时，系统不仅会把该角色设为所属档案的当前角色，还会将**该档案记录为对应游戏的默认档案**。此后你在日常指令中省略档号时，该游戏指令会自动路由到这个默认档案；若指令中显式带了 `档案N`（例如 `#UID2 档案2`），则只改写指定档案的当前角色，**不会修改该游戏的默认档案**。

### 公开 UID 引用管理（无需登录）

若只希望查询公开角色面板，可使用独立的公开 UID 引用列表（三游各自独立编号 1–99，与登录档案角色互不干扰）：

- 登记：`#登记公开UID <游戏UID>`（对应星铁/绝区零可用 `*` 或 `%` 前缀，下同），校验 8–10 位数字格式与区服后加入列表（每游戏最多 99 个）并设为公开当前。
- 查看：`#公开UID列表` 查看全部公开引用及序号；`#查询公开UID` 或 `#查询公开UID2` 查询指定序号的公开展板角色数。
- 切换与删除：`#切换公开UID2` 切换当前公开引用；`#删除公开UID2` 删除对应序号（直接发送 `#删除UID` 会提示先用 `#公开UID列表` 核对编号再删）。

## 设备绑定与自动设备

米游社社区签到与部分防风控接口需要匹配的 `device_id` 与 13 位十六进制设备指纹 `fp`。Lotus-Yunzai 支持手动绑定真机设备，也会在未手绑时按需生成自动设备。

### 手动绑定设备（好友私聊）

前提：已加机器人好友，且目标档案已完成 `#扫码登录`。

1. 在好友私聊发送 `#绑定设备`（或 `#绑定设备2`，支持 `#原神` / `#星铁` / `#绝区零` / `%` 前缀；查看简短提示可用 `#绝区零绑定设备帮助`）。
2. 系统进入 **120 秒（两分钟）**等待窗口，并尝试向私聊发送设备信息提取工具 `copy_device_info_1.2.apk`（若当前连接不支持传文件或本地文件不可用，会提供下载链接；你也可以直接发送手头已有的设备资料）。
3. 在两分钟内发送设备资料（也可以在第一步直接发送 `#绑定设备2 <设备JSON或字段>` 一次性提交）：
   - **方式 A：发送真机配对参数**：在同一条消息中提供同一真实设备的 `device_id`（8–128 位字母、数字、`_` 或 `-`）和 13 位十六进制 `device_fp`（`fp`），可选附带 `device_name`、`device_model`、`android_version`。
   - **方式 B：发送工具 APK 导出的完整安卓 JSON**：当 JSON 中不含 `device_id` / `device_fp`，但包含完整安卓设备参数（`deviceName`、`deviceModel`、`deviceFingerprint`、`deviceProduct`、`deviceBoard` 及有效的 `oaid`）时，系统会自动补齐设备标识并向官方申请 `fp`。
4. 绑定成功后，系统会提示你**在 QQ 中自行撤回刚才发送的设备资料消息**。

字段文本模板（仅作格式占位，请替换为真实设备提取结果，勿填写失效或虚构的 `fp`）：

```text
device_id=<真实设备ID>
device_fp=<13位十六进制设备指纹>
```

> **提交注意事项**
> - 不要提交含 `ext_fields`、`seed_id` 的指纹申请请求体，也不要提交非成功的响应报文。
> - 若导出的 JSON 中 `oaid` 为空或以 `error_` 开头，请重新运行 APK 获取有效参数后再提交。
> - 等待期间发送 `#取消绑定设备`（或 `#取消绑定设备2`，或直接发送 `取消`）可立即退出等待。

### 自动设备、覆盖关系与解绑

- **查看设备状态**：发送 `#设备信息` / `#设备信息2`（或 `#配置` / `#配置2`），可查看当前是“已绑定”（手绑真机）、“自动设备”（含是否已取得 `FP`）还是“未绑定”。
- **覆盖优先级**：
  - **手工绑定会覆盖自动设备**：一旦通过 `#绑定设备` 保存真机设备，该档案将转为使用手工绑定设备。
  - **后台生成不覆盖已手绑/完整旧设备**：后台自动设备维护任务只会为未手动绑定且缺少有效设备标识（或仅含早期占位标识）的已登录档案生成安卓参数并定期申请指纹；不会改动任何已手动绑定的设备或完整的旧设备资料。
- **解绑设备**：在本人好友私聊发送 `#解绑设备` 或 `#解绑设备2`，仅将设备重置为未绑定状态，**保留当前档案的登录凭据与角色设置**。

## 国际服 Cookie 与云游戏 Token

国际服（HoYoLAB）与国服云游戏（云原神、云绝区零）的凭据**必须绑定在已本地登录（`loggedIn`）的档案上**。米游社扫码登录**不会**自动获得或替代国际服 Cookie 与云游戏 Token。

### 国际服（HoYoLAB）配置

1. **绑定国际服 Cookie（仅限好友私聊）**：发送 `#绑定国际服Cookie <Cookie>` 或 `#绑定国际服Cookie2 <Cookie>`（也支持“海外服”写法）。系统会先联网核验 Cookie 有效性及其 HoYoLAB 账号身份（不要求与国服米游社通行证同号），核验通过后写入指定档案。
2. **开启或关闭签到**：发送 `#开启国际服签到` / `#关闭国际服签到`（可加档号如 `#开启国际服签到2`，支持 `启用`、`禁用` 及省略“签到”二字）。
3. **设置语言**：发送 `#设置国际服语言 <语言代码>` 或 `#设置国际服语言2 <语言代码>`（例如 `zh-cn`、`en-us`；语言代码须为 1–32 位字母、`_` 或 `-`，不允许数字）。

### 云原神与云绝区零配置

请从正常登录的官方云游戏客户端或网页会话获取自身真实凭据，切勿在群聊或终端发送凭据，也不要自行构造或猜测 Token。

| 操作 | 云原神指令 | 云绝区零指令 | 说明 |
| :--- | :--- | :--- | :--- |
| **绑定凭据（好友私聊）** | `#绑定云原神Token <Token>` | `#绑定云绝区零Token <Token>` | 档号写在 `Token` 后（如 `#绑定云原神Token2 <Token>`）；保存前会试读钱包验证有效性 |
| **开启/关闭签到** | `#开启云原神签到` / `#关闭云原神签到` | `#开启云绝区零签到` / `#关闭云绝区零签到` | 支持 `启用`/`禁用` 与档号后缀（如 `#开启云原神签到2`） |
| **查询云原神钱包** | `#云原神查询` / `#云原神查询2` | — | 查看对应档案的米云币、免费时长与总时长 |
