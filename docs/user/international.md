# 国际服使用说明

本文档适用于接入 HoYoLAB 及海外游戏区服的相关功能说明与操作指引。

## 1. 账号接入与凭据绑定

国际服凭据与国服凭据在同一档案中独立存储互不覆盖，且无需以已登录国服为前提条件。

### 方式一：网页登录授权（推荐）

* **触发指令**：`#国际服登录` 或 `#国际服登录[档号]`（如 `#国际服登录2`，默认档案 1）。
* **说明**：可在群聊或好友私聊中发送指令，机器人将生成专属登录网页。仅支持账密登录及后续邮箱安全验证（不支持扫码授权）。登录完成后系统会自动同步海外服游戏角色。

### 方式二：私聊直接绑定 SToken

仅支持 SToken v2，必须包含 `mid`。指令格式（请在好友私聊中发送）：

`#绑定国际服SToken[档号] stuid=100000000; stoken=v2_dummy_token_value; mid=dummy_mid; ma_passport_region=SG`

* 参数说明：`ma_passport_region` 填写通行证所在地区（可选 `SG` / `US` / `EU`）。必须包含 `mid`。
* 处理逻辑：录入后联网核验、换取票据并同步海外角色；支持识别并导入海外服别名，未建档时可独立初次建档。

### 方式三：Cookie 附加绑定

* 指令：`#绑定国际服Cookie`
* 限制：仅作为附加凭据补充，需要当前档案已存在登录记录。

## 2. 档案管理与多角色切换

* **查看状态**：`#登录列表`、`#角色列表`
* **切换角色**：`#切换角色序号`（原神）、`*切换角色序号`（星穹铁道）、`%切换角色序号`（绝区零）
* **凭据维护**：后台每 15 分钟检查，满 2 小时换票。同一国际服账号重登才保留原设置。

## 3. 抽卡记录同步说明

* **原神**：`#更新抽卡记录`，国际服支持常驻、角色、武器、集录四池自动授权获取。
* **绝区零**：`%更新抽卡记录`，国服及国际服六频段自动授权更新，失败可按录入流程导入官方链接。好友私聊发送 `%获取抽卡链接` 可返回本人国服/国际服官方链接。
* **崩坏：星穹铁道**：国服使用小程序接口同步；海外服自动授权接口目前不可用，请通过备用链路手动导入：在好友私聊中先发送 `*抽卡链接`，于 2 分钟内发送游戏内抓取的官方跃迁 URL。

## 4. 游戏兑换码（手动与自动）

### 手动兑换（好友私聊）

* 原神：`#兑换码使用CODE`（指定档案如 `#兑换码使用CODE 档案2`）
* 星穹铁道：`*兑换码使用CODE`
* 绝区零：`%兑换码使用CODE`

### 自动扫描与兑换

* 沿用各游戏原有的自动兑换功能开关，内部独立隔离国服与国际服数据源与账本记录。
* 系统每 5 分钟扫描 HoYoLAB 官方发布渠道；同角色同码记账防重。
* 自动任务仅处理现有已注册自动兑换的档案。

## 5. 绝区零战绩与群内功能

* **战绩与面板**：支持国服/HoYoLAB 本人角色面板展示与战绩卡片。
* **群排行榜与挑战提醒**：本次群榜和挑战提醒支持国际服；榜单周期依服务器所属时区计算，推送提醒按北京时间触发；未开启提醒的用户不会自动开启。
