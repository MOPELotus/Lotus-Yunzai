# 语言与文案

项目只预置简体中文（`zh-CN`）。机器人回执、终端与初始化日志、图片标签、管理网页、米游社网页及兼容模板文案均按功能集中管理。命令、协议字段、权限标识、角色别名、游戏资料和资源路径属于业务数据，不随界面语言改变。

## 在管理面板修改

主人在机器人好友私聊发送 `#管理面板`，打开登录链接，进入「语言与文案」。

1. 选择模块和功能，或搜索当前文案。
2. 核对功能说明、源码位置、默认文案和参数说明，再修改内容。
3. 保存后点击「应用更改」。机器人受控重启，所有启动时缓存的文字一起更新。

面板修改保存在 `config/i18n/<语言>.json`，不会改写内置中文文件；当前语言保存在 `config/i18n/settings.json`。这些是本机配置，不提交 Git。启动、初始化及机器人运行使用同一语言设置。管理面板会在切换后重新加载，未翻译的条目回退简体中文。

## 添加自己的语言文件

从面板下载中文模板，保留消息键与参数，把需要的文案改好，保存为 `i18n/languages/<语言标记>.json`，例如 `en-US.json`。重新打开「语言与文案」或刷新语言列表即可发现，无需重新构建网页。选择语言后，点击「应用更改」。只翻译一部分也可以。

文件结构如下。`name` 是面板语言选项的显示名称，`messages` 下按模块命名空间分组；例子仅说明格式，项目不内置其他语言。

```json
{
  "name": "我的语言",
  "messages": {
    "core": {
      "消息键": "修改后的文案"
    },
    "genshin": {},
    "panel": {}
  }
}
```

请以下载的完整模板中的实际消息键为准。语言文件只接受 JSON 字符串，不执行 JavaScript 或模板代码。文件上限为 16 MiB，不能使用符号链接。

## 文件中的说明

内置文件分布：

| 位置 | 功能 |
| --- | --- |
| `i18n/zh-CN.json` | 核心回执、账号与签到命令、启动初始化、日志、米游社网页动态内容 |
| `plugins/<插件>/i18n/zh-CN.json` | 对应插件的命令回执、图片文案、业务提示 |
| `packages/<包>/i18n/zh-CN.json` | 账号、游戏接口、抽卡记录与通用图片组件 |
| `panel/i18n/zh-CN.json` | 管理网页 |
| `i18n/legacy-templates/zh-CN.json` | 兼容 HTML/CSS 模板与米游社网页静态文字 |
| `i18n/legacy-plugin/zh-CN.json` | 兼容插件基类提示 |

每个文件都包含 `description`（模块说明）、`sections`（功能说明和源码位置）、`messages`（文案）与 `parameters`（参数来源）。消息键用于引用，修改文本即可，勿重命名已有消息键。

`{name}`、`{profileId}`、`{value1}` 等是运行时参数。可调整参数顺序，保留参数名；`parameters` 会注明对应源码表达式。参数只替换一次，插入的用户文本不会继续作为模板执行。`\n` 表示换行。不要修改文案内需要用户实际输入的命令拼写。

## 开发维护

新增文案放到所属模块的中文文件，补上功能说明和参数来源，再用共享 `createTranslator` 引用。业务判断使用稳定标识或结构化状态，不能解析翻译后的句子判断是否成功。

运行 `bun run i18n:check` 核对消息引用、功能说明和参数。兼容的上游原模板保留原文件及校验值，展示文案通过模板加载器替换，不改动游戏资料或原素材。
